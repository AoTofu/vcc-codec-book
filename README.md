# 小学生でもわかる VCC コーデック

VVC (Versatile Video Coding / H.266) の仕組みを、図と数式を使ってやさしく紹介するPDFブックです。

GitHub Pages: https://aotofu.github.io/vcc-codec-book/

- `VCC_codec_for_kids.pdf` - GitHub ActionsでLaTeXから自動生成する本編PDF
- `cover.png` - PDF第1ページから自動生成する表紙プレビュー
- `index.html` - GitHub Pages用トップページ
- `source-parts/` - 再現可能なLaTeXソースZIPの転送用データ

表紙では依頼どおり「VCC」を使っていますが、本文で扱う正式な規格名は VVC / H.266 です。
